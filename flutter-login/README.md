# Flutter Login UI

This namespace contains the onboarding, sign-in, and sign-up screen prototypes:

- [`onboarding_screen.dart`](./lib/pages/onboarding_screen.dart)
- [`signin.dart`](./lib/pages/signin.dart)
- [`signup.dart`](./lib/pages/signup.dart)

These are source snippets rather than a complete Flutter application. A `pubspec.yaml`, app entry point, platform folders, and the referenced image assets are not included, so this project is not currently runnable on its own.

The screens use the `registration_form` package import path and reference `images/dumbbells.png`, `images/social.png`, `images/instagram.png`, and `images/google.png`. Those dependencies must be supplied when turning these prototypes into a runnable app.
